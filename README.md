# Sales Data Analysis & Reporting Dashboard

A portfolio project demonstrating practical **Data Analyst** skills using SQL and Excel.

## Skills Demonstrated

- SQL data querying and aggregation
- Excel / Google Sheets reporting
- Data cleaning and validation
- KPI calculation
- Business analytics
- Revenue and sales trend analysis
- Data visualization

## Business Questions

- What is total revenue and total units sold?
- Which products generate the most revenue?
- Which regions perform best?
- How does revenue change month to month?
- Which sales channel performs best?
- What is the average order value?

## Data Cleaning

The project demonstrates:
- Missing-value handling

- Whitespace/inconsistent category cleanup
- Revenue recalculation
- Basic data validation
